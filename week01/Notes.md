For each type of Cloud service model here are real AWS services for each category

Infrastructure as a Service (IaaS)IaaS provides the raw, foundational building blocks of virtualized hardware, offering maximum control over networking, computers, and data storage.Compute: Amazon EC2 (Elastic Compute Cloud), Amazon VPCStorage: Amazon EBS (Elastic Block Store), Amazon S3Networking: Amazon VPC, Amazon Route 53

Platform as a Service (PaaS)PaaS removes the need to manage underlying hardware, supplying a managed environment focused on deploying and scaling applications.Application Hosting: AWS Elastic Beanstalk, AWS App RunnerDatabases (Managed): Amazon RDS, Amazon AuroraContainers: Amazon ECS (Elastic Container Service), Amazon EKS (Elastic Kubernetes Service)

Software as a Service (SaaS)SaaS delivers complete, ready-to-use end-user software applications managed entirely by the provider.Business Productivity: Amazon WorkDocs, Amazon WorkMail

For a quick student side-project I would use a PaaS or a SaaS vs. a production app i want full control over id use an IaaS
